# StorageDefinition

Represents a storage definition in the domain layer, containing information about a storage entity including its unique identifier and display name.

## Properties

- `storageId`: String - The unique identifier for the storage
- `displayName`: String? - The display name for the storage (optional)

## Usage

This model is typically used to represent storage configurations or locations in the ETL system, allowing for identification and presentation of storage entities in the application.
