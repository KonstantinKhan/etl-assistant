# DoubleProperty

## Responsibility
- Definition for double properties
- Specifies constraints and characteristics for double property values
- Enables validation and processing of double properties

## Fields
- `name`: String? - Name of the property
- `description`: String? - Description of the property
- `minValue`: Double? - Minimum allowed value
- `maxValue`: Double? - Maximum allowed value
- `defaultValue`: Double? - Default value for the property
- `unit`: String? - Unit of measurement

## Used by
- Numeric property definition systems
- Schema validation mechanisms
- Property constraint systems
