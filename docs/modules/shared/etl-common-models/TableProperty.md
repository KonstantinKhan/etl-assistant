# TableProperty

## Responsibility
- Definition for table properties
- Specifies structure and characteristics for table property values
- Enables validation and processing of table properties

## Fields
- `name`: String? - Name of the property
- `description`: String? - Description of the property
- `columns`: List<TableColumn>? - List of column definitions
- `maxRows`: Int? - Maximum number of allowed rows

## Used by
- Table property definition systems
- Structured data management
- Spreadsheet integration systems
