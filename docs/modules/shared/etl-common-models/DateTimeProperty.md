# DateTimeProperty

## Responsibility
- Definition for datetime properties
- Specifies characteristics for datetime property values
- Enables validation and processing of datetime properties

## Fields
- `name`: String? - Name of the property
- `description`: String? - Description of the property
- `defaultValue`: String? - Default datetime value in ISO format
- `format`: String? - Format string for the datetime

## Used by
- Datetime property definition systems
- Schema validation mechanisms
- Temporal data management systems
