# DoublePropertyValues

## Responsibility
- Represents values for numeric properties with min/max bounds and tolerance
- Provides type-safe handling of double values with constraints
- Enables validation of numeric property values

## Fields
- `value`: Double? - The actual double value
- `minValue`: Double? - Minimum allowed value
- `maxValue`: Double? - Maximum allowed value
- `tolerance`: Double? - Tolerance for value comparison

## Used by
- Numeric property validation systems
- Constraint checking mechanisms
- Value normalization processes
