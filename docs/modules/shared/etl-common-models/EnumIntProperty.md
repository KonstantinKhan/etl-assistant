# EnumIntProperty

## Responsibility
- Definition for integer enum properties
- Specifies possible integer values for enum property values
- Enables validation and processing of integer enum properties

## Fields
- `name`: String? - Name of the property
- `description`: String? - Description of the property
- `possibleValues`: List<Int>? - List of possible integer values
- `defaultValue`: Int? - Default value for the property

## Used by
- Integer enum property definition systems
- Integer selection systems
- Integer validation mechanisms
