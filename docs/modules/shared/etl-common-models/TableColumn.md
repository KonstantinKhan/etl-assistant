# TableColumn

## Responsibility
- Definition for table columns
- Specifies structure and characteristics for table columns
- Enables validation and processing of table column definitions

## Fields
- `name`: String? - Name of the column
- `dataType`: String? - Data type of the column
- `width`: Double? - Width of the column
- `isRequired`: Boolean? - Whether the column is required

## Used by
- Table structure definition systems
- Column definition systems
- Table validation mechanisms
