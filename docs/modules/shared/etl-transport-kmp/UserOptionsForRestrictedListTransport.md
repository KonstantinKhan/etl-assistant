# UserOptionsForRestrictedListTransport

## Responsibility
- Represents user options for restricted lists in transport layer
- Contains user preferences for restricted list handling
- Used for restricted list management systems
- Enables user preference systems

## Fields
- `name`: String? - Name of the user option for restricted list
- `objectId`: Int - Object identifier
- `typeId`: Int - Type identifier

## Used by
- Restricted list management systems
- User preference systems
