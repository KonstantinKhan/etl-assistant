# EnumIntPropertyValues

## Responsibility
- Represents integer enumerated values
- Provides type-safe handling of integer enumeration property values
- Enables management of integer predefined value sets

## Fields
- `value`: Int? - The selected integer enumeration value
- `possibleValues`: List<Int>? - List of possible integer enumeration values

## Used by
- Integer enumeration property systems
- Integer selection systems
- Integer validation mechanisms
