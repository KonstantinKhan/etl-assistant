# IntegerProperty

## Responsibility
- Definition for integer properties
- Specifies constraints and characteristics for integer property values
- Enables validation and processing of integer properties

## Fields
- `name`: String? - Name of the property
- `description`: String? - Description of the property
- `minValue`: Int? - Minimum allowed value
- `maxValue`: Int? - Maximum allowed value
- `defaultValue`: Int? - Default value for the property

## Used by
- Integer property definition systems
- Schema validation mechanisms
- Property constraint systems
