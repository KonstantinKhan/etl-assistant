# EnumDoubleProperty

## Responsibility
- Definition for double enum properties
- Specifies possible double values for enum property values
- Enables validation and processing of double enum properties

## Fields
- `name`: String? - Name of the property
- `description`: String? - Description of the property
- `possibleValues`: List<Double>? - List of possible double values
- `defaultValue`: Double? - Default value for the property

## Used by
- Double enum property definition systems
- Double selection systems
- Double validation mechanisms
