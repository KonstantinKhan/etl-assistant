# Identifier

## Responsibility
- Combines ObjectId and TypeId to uniquely identify domain objects in the system
- Provides a unified way to reference objects across the application
- Serves as a foundational element for object identification

## Fields
- `objectId`: ObjectId - Unique identifier for the object
- `typeId`: TypeId - Type identifier for the object

## Used by
- Object referencing systems
- Cross-referencing mechanisms
- Identification systems throughout the application
