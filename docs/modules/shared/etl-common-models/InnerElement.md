# InnerElement

## Responsibility
- Represents elements contained within other elements
- Models containment relationships between objects
- Enables composition patterns in the domain

## Fields
- `identifier`: Identifier - Unique identifier for the inner element
- `name`: String? - Name of the inner element
- `elementType`: String? - Type of the inner element

## Used by
- Composition systems
- Containment relationship management
- Nested element handling
