# EnumDoublePropertyValues

## Responsibility
- Represents double enumerated values
- Provides type-safe handling of double enumeration property values
- Enables management of double predefined value sets

## Fields
- `value`: Double? - The selected double enumeration value
- `possibleValues`: List<Double>? - List of possible double enumeration values

## Used by
- Double enumeration property systems
- Double selection systems
- Double validation mechanisms
