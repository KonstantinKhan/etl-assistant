# EnumBoolPropertyValues

## Responsibility
- Represents boolean enumerated values
- Provides type-safe handling of boolean enumeration property values
- Enables management of boolean predefined value sets

## Fields
- `value`: Boolean? - The selected boolean enumeration value
- `possibleValues`: List<Boolean>? - List of possible boolean enumeration values

## Used by
- Boolean enumeration property systems
- Boolean selection systems
- Boolean validation mechanisms
