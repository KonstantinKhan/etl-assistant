# Model Index

This document provides brief descriptions of each mapping component in the etl-mapper module.

## Mapping Components

### [Domain2Transport](Domain2Transport.md)
Provides extension functions to convert domain models to transport models, enabling serialization of internal domain objects for API communication.

### [Transport2Domain](Transport2Domain.md)
Provides extension functions to convert transport models back to domain models, enabling deserialization of external data into internal domain objects.
