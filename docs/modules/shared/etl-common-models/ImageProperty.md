# ImageProperty

## Responsibility
- Definition for image properties
- Specifies characteristics for image property values
- Enables validation and processing of image properties

## Fields
- `name`: String? - Name of the property
- `description`: String? - Description of the property
- `defaultValue`: String? - Default image reference
- `allowedFormats`: List<String>? - List of allowed image formats
- `maxSize`: Long? - Maximum allowed image size in bytes

## Used by
- Image property definition systems
- Media management systems
- File validation mechanisms
