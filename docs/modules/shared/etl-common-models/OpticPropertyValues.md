# OpticPropertyValues

## Responsibility
- Represents material properties for visualization
- Provides type-safe handling of optical property values
- Enables visualization of materials with specific optical characteristics

## Fields
- `refractiveIndex`: Double? - Refractive index of the material
- `transparency`: Double? - Transparency level
- `reflectivity`: Double? - Reflectivity level

## Used by
- Material visualization systems
- Rendering engines
- Optical simulation systems
