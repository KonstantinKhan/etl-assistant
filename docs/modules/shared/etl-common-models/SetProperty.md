# SetProperty

## Responsibility
- Definition for set properties
- Specifies characteristics for set property values
- Enables validation and processing of set properties

## Fields
- `name`: String? - Name of the property
- `description`: String? - Description of the property
- `possibleValues`: List<SetItem>? - List of possible set values
- `defaultValue`: Set<String>? - Default set of values

## Used by
- Set property definition systems
- Multi-selection systems
- Tagging mechanisms
