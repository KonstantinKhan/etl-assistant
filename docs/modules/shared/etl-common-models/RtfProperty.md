# RtfProperty

## Responsibility
- Definition for RTF properties
- Specifies characteristics for rich text format property values
- Enables validation and processing of RTF properties

## Fields
- `name`: String? - Name of the property
- `description`: String? - Description of the property
- `defaultValue`: String? - Default RTF content

## Used by
- RTF property definition systems
- Document management systems
- Text formatting systems
