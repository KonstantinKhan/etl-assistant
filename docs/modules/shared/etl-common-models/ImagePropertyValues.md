# ImagePropertyValues

## Responsibility
- Represents image references
- Provides type-safe handling of image property values
- Enables management of image-based properties

## Fields
- `reference`: String? - Reference to the image resource
- `mimeType`: String? - MIME type of the image
- `size`: Long? - Size of the image in bytes

## Used by
- Image property handling systems
- Media management systems
- UI display systems
