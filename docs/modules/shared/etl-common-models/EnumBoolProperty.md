# EnumBoolProperty

## Responsibility
- Definition for boolean enum properties
- Specifies possible boolean values for enum property values
- Enables validation and processing of boolean enum properties

## Fields
- `name`: String? - Name of the property
- `description`: String? - Description of the property
- `possibleValues`: List<Boolean>? - List of possible boolean values
- `defaultValue`: Boolean? - Default value for the property

## Used by
- Boolean enum property definition systems
- Boolean selection systems
- Boolean validation mechanisms
