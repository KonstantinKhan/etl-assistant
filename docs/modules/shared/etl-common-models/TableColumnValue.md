# TableColumnValue

## Responsibility
- Represents a column definition in a table
- Provides type-safe handling of table column information
- Enables management of table structure properties

## Fields
- `name`: String? - Name of the column
- `dataType`: String? - Data type of the column
- `width`: Double? - Width of the column

## Used by
- Table structure management
- Column definition systems
- Table rendering systems
