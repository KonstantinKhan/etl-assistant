# GuidProperty

## Responsibility
- Definition for GUID properties
- Specifies characteristics for globally unique identifier property values
- Enables validation and processing of GUID properties

## Fields
- `name`: String? - Name of the property
- `description`: String? - Description of the property
- `defaultValue`: String? - Default GUID value

## Used by
- GUID property definition systems
- Unique identifier systems
- Cross-system referencing mechanisms
