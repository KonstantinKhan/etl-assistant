# OwnerGroup

## Responsibility
- Represents ownership groups for access control
- Manages permissions and access rights for domain objects
- Enables role-based access control mechanisms

## Fields
- `groupId`: GroupId - Unique identifier for the group
- `groupName`: String? - Name of the owner group
- `permissions`: List<String>? - Permissions associated with the group

## Used by
- Access control systems
- Permission management
- Security frameworks
