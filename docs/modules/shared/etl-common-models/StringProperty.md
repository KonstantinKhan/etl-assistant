# StringProperty

## Responsibility
- Definition for string properties
- Specifies constraints and characteristics for string property values
- Enables validation and processing of string properties

## Fields
- `name`: String? - Name of the property
- `description`: String? - Description of the property
- `maxLength`: Int? - Maximum length of the string
- `defaultValue`: String? - Default value for the property
- `pattern`: String? - Regular expression pattern for validation

## Used by
- Text property definition systems
- Schema validation mechanisms
- Property constraint systems
