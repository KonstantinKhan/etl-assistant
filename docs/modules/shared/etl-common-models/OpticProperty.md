# OpticProperty

## Responsibility
- Definition for optic properties
- Specifies characteristics for optic property values
- Enables definition of material optical properties

## Fields
- `name`: String? - Name of the property
- `description`: String? - Description of the property
- `defaultRefractiveIndex`: Double? - Default refractive index
- `defaultTransparency`: Double? - Default transparency level
- `defaultReflectivity`: Double? - Default reflectivity level

## Used by
- Optic property definition systems
- Material definition systems
- Visualization systems
