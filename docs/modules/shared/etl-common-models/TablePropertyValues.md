# TablePropertyValues

## Responsibility
- Represents tabular data with columns and rows
- Provides type-safe handling of table property values
- Enables management of structured data properties

## Fields
- `columns`: List<TableColumnValue>? - List of column definitions
- `rows`: List<TableRowValue>? - List of row data

## Used by
- Table property handling systems
- Structured data management
- Spreadsheet integration systems
